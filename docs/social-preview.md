# Social preview

The current AI Engineering Guardrails social-preview artwork is stored at
[`docs/assets/social-preview-ai-engineering-guardrails.png`](assets/social-preview-ai-engineering-guardrails.png).
It is a visual summary of the project, not a status signal or security claim.
The earlier [`social-preview.png`](assets/social-preview.png) remains intact
as historical artwork.

The image is intentionally kept in the repository so maintainers can review
branding changes through the same pull-request process as code and policy.
Keep the asset at 1280 × 640 pixels and below 1 MB so it matches
[GitHub's recommended social-preview format and upload limit](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/customizing-your-repositorys-social-media-preview).

To apply it on GitHub, open **Settings → General → Social preview**, upload the
PNG, and save. GitHub does not expose a supported repository-edit API for
uploading this image, so the committed asset and the GitHub setting are kept
separate deliberately.
